# Project ADONIS

A mobile-first 75-day habit, study, fitness, and confidence tracker.

## Run locally

1. Install Node.js (LTS).
2. Clone this repository.
3. In the project folder, run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed in your terminal.

## Features

- Daily habit checklist with progress tracking
- 75-day journey phases
- Study focus sprint presets and study method reminders
- Fitness and soccer planning sections
- Daily reflection and confidence challenge
- Responsive dark interface
- Saves check-ins in the browser using local storage

## Notes

The journey starts November 1, 2026. Data is currently stored locally in the browser on the device being used; it does not sync between devices yet.
